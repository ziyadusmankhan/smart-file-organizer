Smart File Organizer

A Python automation tool that automatically organizes files into categorized folders such as Images, Videos, and Documents.

Features
Scans selected directories
Automatically sorts files by extension
Creates folders if they don't exist
Moves files into their appropriate categories
Supported Categories
Images
.jpg
.jpeg
.png
Videos
.mp4
.mkv
Documents
.pdf
.docx
.txt
Technologies Used
Python
os
shutil
Usage

Run:

python main.py

The program will scan the target directory and organize files automatically.
